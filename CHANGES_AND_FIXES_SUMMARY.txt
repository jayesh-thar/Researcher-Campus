1. LIVE 5-ENGINE ACADEMIC API HARVESTER INTEGRATION
================================================================================
File: server/src/services/literatureService.ts

[WHAT WAS WRONG BEFORE]
The file defined endpoint URLs for Crossref, arXiv, OpenAlex, Semantic Scholar,
and Europe PMC, but never made actual HTTP requests to them. Instead, it only
called Gemini to generate synthetic paper titles and abstracts.

[WHAT WAS CHANGED]
Implemented 5 dedicated live HTTP fetcher functions with 4.5s timeout guards
and AbortController signal handling:
1. harvestFromCrossref(query): Queries https://api.crossref.org/works?query=...
   Extracts real titles, authors, DOIs, publication years, container journals.
2. harvestFromArxiv(query): Queries https://export.arxiv.org/api/query?search_query=...
   Parses real Atom XML preprints, summaries, author rosters, and arXiv links.
3. harvestFromOpenAlex(query): Queries https://api.openalex.org/works?search=...
   Extracts real scholarly works, primary locations, and DOIs.
4. harvestFromSemanticScholar(query): Queries https://api.semanticscholar.org/graph/v1/paper/search
   Fetches real papers with projected fields (title, authors, year, abstract, venue, url).
5. harvestFromEuropePMC(query): Queries https://www.ebi.ac.uk/europepmc/webservices/rest/search
   Searches biomedical and computer science literature.

All 5 engines execute concurrently via Promise.allSettled(), merge results,
deduplicate by sanitized title and DOI, and map into ILiteratureItem[].

2. TRUE MATHEMATICAL VECTOR COSINE SIMILARITY & EMBEDDINGS
================================================================================
File: server/src/services/literatureService.ts

[WHAT WAS WRONG BEFORE]
The similarity function used a simple Jaccard word-set intersection over union
ratio on words longer than 3 letters, while documentation mentioned vector cosine
similarity.

[WHAT WAS CHANGED]
1. Implemented computeVectorCosineSimilarity(vecA, vecB) implementing the exact
   mathematical vector dot product / Euclidean norm formula:
   CosineSimilarity = (A . B) / (||A|| * ||B||)
2. Integrated Google Gemini text-embedding-004 (producing true 768-dimensional
   float embedding vectors) via calculateLiveEmbeddingSimilarity(textA, textB).
3. Implemented calculateTfIdfVectorCosineSimilarity(textA, textB) as a multi-
   dimensional TF-IDF N-gram (unigram + bigram) vector space fallback for
   offline environments.

4. currentStage MONGOOSE SCHEMA FIELD PERSISTENCE FIX
================================================================================
File: server/src/models/Project.ts

[WHAT WAS WRONG BEFORE]
Route files (aiRoutes.ts, auditRoutes.ts, driveRoutes.ts, literatureRoutes.ts,
roadmapRoutes.ts) wrote to project.currentStage (e.g. project.currentStage = 2),
but the Project.ts Mongoose schema never declared currentStage. Due to Mongoose
strict mode, all writes to currentStage were silently dropped.

[WHAT WAS CHANGED]
Added currentStage to both the TypeScript IProject interface and Mongoose ProjectSchema:
  currentStage: { type: Number, default: 1 }

7. STRICT CORS ORIGIN WHITELIST POLICY ENFORCEMENT IN PRODUCTION
================================================================================
File: server/src/index.ts

[WHAT WAS WRONG BEFORE]
The CORS origin callback ended with `return callback(null, true);`, allowing any
unlisted origin to make cross-origin requests.

[WHAT WAS CHANGED]
Enforced strict origin checking: if NODE_ENV === 'production' and the requesting
origin is not in the whitelist (CLIENT_URL, *.vercel.app, *.onrender.com, localhost),
it is explicitly rejected with a CORS policy error.
